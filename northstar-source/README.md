# Northstar

A React + Vite streaming discovery app built with AppDeploy.

## Run locally

1. Install Node.js.
2. In this folder, run `npm install`.
3. Run `npm run dev` and open the local URL printed in the terminal.

The project includes the Northstar catalog, search, title details, responsive browse rows, and a browser-local My List. Video playback is not connected; the Play controls are demo actions.
